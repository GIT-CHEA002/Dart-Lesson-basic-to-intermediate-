## Under standing dart prooject Structure

my_project/
├── .dart_tool/          # Generated by tooling (build cache, package config)
├── .git/
├── bin/                 # Executable entry points
│   └── my_project.dart
├── lib/                 # Main source code (importable/reusable)
│   ├── src/             # Private implementation details
│   │   └── some_class.dart
│   └── my_project.dart  # Public API — exports what's in src/
├── test/                # Unit/widget tests
│   └── my_project_test.dart
├── example/             # Example usage (common in packages)
├── analysis_options.yaml # Linter/analyzer rules
├── pubspec.yaml         # Project metadata & dependencies
├── pubspec.lock         # Locked dependency versions
├── CHANGELOG.md
├── README.md
└── LICENSE
